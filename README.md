# Dividend tax calculator

A browser-based calculator comparing Finnish unlisted-company dividend taxation across seven scenarios. Includes scenario graphs, light and dark themes, calculation explanations, and Excel (.xlsx), JSON and print/PDF exports.

## Open locally

Open index.html in your browser. Everything is included in this single HTML file. No installation, build step, server or API key is required.

## Files

- index.html — complete calculator with embedded styles, scripts and scenario data.
- JSZip-LICENSE.md — license for the bundled Excel export dependency.
- THIRD_PARTY_NOTICES.md — dependency attribution.
- .nojekyll — serves the site as plain static files.

## Data and privacy

Calculations and exports run in the browser. No financial input is sent to a server. The light/dark theme preference is stored locally in the browser.

Scenario parameters and numeric names were imported from DividendCaluclations.xlsx, Sheet1, on 11 November 2026. The single-party Vasemmistoliitto option was subsequently updated from published party plans: 21% company tax and shared progressive taxation, estimated with your entered incremental income-tax rate. It retains an explicit assumption of 85% taxable / 15% exempt listed-dividend treatment. The 40% sample rate is not a party proposal, and the calculator does not derive a complete progressive assessment. Set the rate to reflect combined earned and capital income and personal circumstances. The original spreadsheet is not needed to use this version. Further spreadsheet changes do not automatically update the calculator.

## Disclaimer

For estimation purposes only, not tax advice.

Political scenarios are rough estimates made by AI based on parties' plans and leaders' statements. Coalition (party-mix) estimates are generated by AI, not confirmed agreements. The scenarios may contain unintentional errors or misinformation. Use them for informal comparison only, not as official party proposals or reliable predictions. Verify original sources before drawing conclusions.

The current-law baseline uses 2026 assumptions, last checked on 9 November 2026. The calculator does not automatically retrieve later changes in legislation.


Numeric scenario codes are the primary labels. Smaller quoted party names are illustrative labels, not official proposals. This hierarchy is also used in graphs and exports.

Sources for that update: [2026 alternative budget](https://vasemmisto.fi/ohjelmat/vasemmistoliiton-vaihtoehtobudjetti-2026/) and [27 August 2026 proposals](https://vasemmisto.fi/artikkelit/vasemmistoliiton-ratkaisuja-julkisen-talouden-tasapainottamiseen/), checked 11 November 2026. Coalition estimates retain their previous assumptions.


“Show AI party estimates” is unchecked by default. Numeric scenario codes remain visible; checking the box shows the illustrative party labels in the results, graphs and exports. Calculations are unchanged. The first four scenarios are Current legislation, SDP, Vasemmistoliitto, and Vasemmistoliitto + SDP.
